# Filmes Favoritos

Atividade de Desenvolvimento Android Moderno (Navigation Compose).

# Tema

Lista de Filmes Favoritos

# Telas

- Splash – abre o app e depois de alguns segundos vai para o Login (ou direto para o Painel se já estiver logado)
- Login – e-mail e senha, qualquer valor funciona
- Painel Principal com Bottom Navigation de 3 abas
- Filmes - lista dos filmes, dá pra marcar como assistido e remover. Quando não tem nenhum filme aparece uma mensagem
- Estatísticas – quantos filmes já foram assistidos
- Perfil – botão de sair da conta
- Detalhe do Filme – abre ao tocar num filme da lista, recebe o id do filme pela rota

# Como rodar

1. Clonar o repositório
2. No Android Studio, ir em File, depois Open e escolher a pasta do projeto
3. Esperar o Gradle sincronizar
4. Rodar em um emulador ou celular com Android 7.0 (API 24) ou superior
